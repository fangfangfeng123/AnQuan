# Database Schema — 自动化安全评估系统

> ORM：SQLAlchemy 2.0（声明式映射）
>
> 数据库：PostgreSQL 16
>
> 命名约定：表名复数小写（`projects`），主键 UUID 前缀 + 短编码（如 `proj_01HXY9`），外键命名 `{引用表单数}_id`

---

## 1. ER 关系总览

```
projects 1──∞ tasks 1──∞ findings
                          │
                  ┌───────┼───────┐
                  ∞       ∞       ∞
            poc_evidence  fix_patches  attack_chain_nodes
                                              │
                                        attack_chain_edges
                                              │
                                         attack_chains
                                              │
tasks 1──∞ task_logs          findings 1──∞ (via finding_id)
tasks 1──∞ audit_logs
tasks 1──∞ reports
projects 1──∞ source_snapshots
```

---

## 2. 表定义

### 2.1 projects — 项目表

```sql
CREATE TABLE projects (
    id              VARCHAR(40)   PRIMARY KEY,          -- proj_01HXY9
    project_name    VARCHAR(200)  NOT NULL,
    source_type     VARCHAR(20)   NOT NULL,             -- git / archive
    source_input    TEXT          NOT NULL,             -- Git URL 或文件标识
    source_ref      VARCHAR(100),                       -- snapshot_a1b2c3
    commit_id       VARCHAR(64),
    tech_stack      JSONB         DEFAULT '[]',          -- ["Python","FastAPI"]
    status          VARCHAR(20)   NOT NULL DEFAULT 'active', -- active / archived
    created_at      TIMESTAMPTZ   NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ   NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_projects_status ON projects(status);
CREATE INDEX idx_projects_created ON projects(created_at DESC);
```

### 2.2 source_snapshots — 源码快照表

```sql
CREATE TABLE source_snapshots (
    id              VARCHAR(40)   PRIMARY KEY,          -- snap_01HXY9
    project_id      VARCHAR(40)   NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
    snapshot_path   TEXT          NOT NULL,             -- /data/snapshots/proj_xxx/
    commit_id       VARCHAR(64),
    file_count      INTEGER,
    total_size_kb   BIGINT,
    checksum        VARCHAR(64),                        -- sha256
    created_at      TIMESTAMPTZ   NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_snapshots_project ON source_snapshots(project_id);
```

### 2.3 tasks — 评估任务表

```sql
CREATE TABLE tasks (
    id              VARCHAR(40)   PRIMARY KEY,          -- task_01HXY9
    project_id      VARCHAR(40)   NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
    sandbox_id      VARCHAR(40),                        -- sbx_01HXY9
    status          VARCHAR(20)   NOT NULL DEFAULT 'created', -- created/running/completed/failed/stopped
    current_phase   VARCHAR(30),                        -- recon/code_audit/poc_verify/exploit_chain/report_gen
    -- 各阶段状态快照
    phase_status    JSONB         DEFAULT '{
        "recon": "pending",
        "code_audit": "pending",
        "poc_verify": "pending",
        "exploit_chain": "pending",
        "report_gen": "pending"
    }',
    sandbox_image   VARCHAR(200)  DEFAULT 'python:3.12-slim',
    network_mode    VARCHAR(20)   DEFAULT 'restricted', -- isolated / restricted
    timeout_secs    INTEGER       DEFAULT 1800,
    llm_mode        VARCHAR(20)   DEFAULT 'demo',       -- openai / ollama / demo
    max_concurrent  INTEGER       DEFAULT 4,
    error_message   TEXT,
    -- 资源使用快照
    resource_usage  JSONB         DEFAULT '{"cpuPercent":0,"memoryMB":0,"diskMB":0,"elapsedSecs":0}',
    started_at      TIMESTAMPTZ,
    ended_at        TIMESTAMPTZ,
    created_at      TIMESTAMPTZ   NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ   NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_tasks_project ON tasks(project_id);
CREATE INDEX idx_tasks_status ON tasks(status);
CREATE INDEX idx_tasks_current_phase ON tasks(current_phase);
```

### 2.4 runtime_profiles — 环境侦察产物表

```sql
CREATE TABLE runtime_profiles (
    id              VARCHAR(40)   PRIMARY KEY,          -- rp_01HXY9
    task_id         VARCHAR(40)   NOT NULL REFERENCES tasks(id) ON DELETE CASCADE,
    language        VARCHAR(50),                        -- Python
    framework       VARCHAR(100),                       -- FastAPI
    dependencies    JSONB         DEFAULT '[]',          -- [{"name":"flask","version":"3.0"},...]
    run_command     TEXT,                               -- python app.py
    service_ports   JSONB         DEFAULT '[]',          -- [8080, 5432]
    entry_points    JSONB         DEFAULT '[]',          -- ["/api/v1/login","/api/v1/orders"]
    db_type         VARCHAR(50),                        -- PostgreSQL
    raw_result      JSONB,                              -- 原始侦察完整结果
    created_at      TIMESTAMPTZ   NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_runtime_profiles_task ON runtime_profiles(task_id);
```

### 2.5 findings — 漏洞表

```sql
CREATE TABLE findings (
    id              VARCHAR(40)   PRIMARY KEY,          -- find_01
    task_id         VARCHAR(40)   NOT NULL REFERENCES tasks(id) ON DELETE CASCADE,
    vuln_type       VARCHAR(100)  NOT NULL,             -- SQL Injection
    cwe_id          VARCHAR(20),                        -- CWE-89
    status          VARCHAR(20)   NOT NULL DEFAULT 'unverified', -- unverified/verified/latent
    severity        VARCHAR(20)   NOT NULL,             -- critical/high/medium/low
    cvss_score      DECIMAL(3,1),                       -- 7.5
    cvss_vector     VARCHAR(200),                       -- AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N

    -- Source 点
    source_file     TEXT,
    source_line     INTEGER,
    source_code     TEXT,

    -- Sink 点
    sink_file       TEXT,
    sink_line       INTEGER,
    sink_code       TEXT,

    -- 污点传播路径
    taint_path      JSONB,                              -- [{"file":"...","line":40,"desc":"..."}]
    code_context    TEXT,                               -- 漏洞上下文完整代码

    -- Agent 信息
    detected_by     VARCHAR(50),                        -- Semgrep / CodeQL / ReconAgent
    confidence      DECIMAL(3,2),                       -- 0.85

    created_at      TIMESTAMPTZ   NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ   NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_findings_task ON findings(task_id);
CREATE INDEX idx_findings_status ON findings(status);
CREATE INDEX idx_findings_severity ON findings(severity);
CREATE INDEX idx_findings_cwe ON findings(cwe_id);
-- 复合索引：任务内按状态+严重等级筛选
CREATE INDEX idx_findings_task_status_severity ON findings(task_id, status, severity);
```

### 2.6 poc_evidence — PoC 验证证据表

```sql
CREATE TABLE poc_evidence (
    id              VARCHAR(40)   PRIMARY KEY,          -- poc_01
    finding_id      VARCHAR(40)   NOT NULL REFERENCES findings(id) ON DELETE CASCADE,
    poc_type        VARCHAR(50)   NOT NULL,             -- boolean_based/time_based/echo_marker/file_read
    request_payload TEXT,                               -- id=1 AND 1=1 -- 
    request_data    TEXT,                               -- 完整 HTTP 请求报文
    response_data   TEXT,                               -- 完整 HTTP 响应报文
    expected_feature TEXT,                              -- 布尔条件为真时返回正常订单数据
    observed_feature TEXT,                              -- 返回了完整订单数据
    verified        BOOLEAN       NOT NULL DEFAULT FALSE,
    verified_at     TIMESTAMPTZ,
    created_at      TIMESTAMPTZ   NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_poc_finding ON poc_evidence(finding_id);
CREATE INDEX idx_poc_verified ON poc_evidence(verified);
```

### 2.7 fix_patches — 修复补丁表

```sql
CREATE TABLE fix_patches (
    id              VARCHAR(40)   PRIMARY KEY,          -- patch_01
    finding_id      VARCHAR(40)   NOT NULL REFERENCES findings(id) ON DELETE CASCADE,
    original_code   TEXT          NOT NULL,
    patched_code    TEXT          NOT NULL,
    diff_content    TEXT          NOT NULL,             -- unified diff
    validation_status VARCHAR(20) NOT NULL DEFAULT 'pending', -- pending/passed/failed
    adopt_status    VARCHAR(20)   NOT NULL DEFAULT 'not_adopted', -- not_adopted/adopted
    -- 校验细节
    syntax_check    BOOLEAN       DEFAULT FALSE,
    compile_check   BOOLEAN       DEFAULT FALSE,
    security_regression_check BOOLEAN DEFAULT FALSE,
    -- LLM 信息
    llm_mode        VARCHAR(20),                        -- openai/ollama/demo
    llm_model       VARCHAR(50),                        -- gpt-4o
    token_usage     INTEGER,
    created_at      TIMESTAMPTZ   NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ   NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_patches_finding ON fix_patches(finding_id);
CREATE INDEX idx_patches_validation ON fix_patches(validation_status);
```

### 2.8 attack_chains — 攻击链表

```sql
CREATE TABLE attack_chains (
    id              VARCHAR(40)   PRIMARY KEY,          -- chain_01
    task_id         VARCHAR(40)   NOT NULL REFERENCES tasks(id) ON DELETE CASCADE,
    final_impact    VARCHAR(200),                       -- 远程代码执行（RCE）
    overall_severity VARCHAR(20),                       -- critical
    node_count      INTEGER       DEFAULT 0,
    edge_count      INTEGER       DEFAULT 0,
    created_at      TIMESTAMPTZ   NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_chains_task ON attack_chains(task_id);
```

### 2.9 attack_chain_nodes — 攻击链节点表

```sql
CREATE TABLE attack_chain_nodes (
    id              VARCHAR(40)   PRIMARY KEY,          -- node_01
    chain_id        VARCHAR(40)   NOT NULL REFERENCES attack_chains(id) ON DELETE CASCADE,
    finding_id      VARCHAR(40)   REFERENCES findings(id) ON DELETE SET NULL,
    label           VARCHAR(200)  NOT NULL,             -- SQL注入点
    asset           TEXT,                               -- 订单查询接口 /api/orders?id=
    pre_condition   TEXT,                               -- 无认证可访问
    post_capability TEXT,                               -- 读取数据库任意表
    privilege_level VARCHAR(50),                       -- anonymous/authenticated/admin
    node_order      INTEGER       NOT NULL              -- 在链中的顺序
);

CREATE INDEX idx_chain_nodes_chain ON attack_chain_nodes(chain_id);
CREATE INDEX idx_chain_nodes_finding ON attack_chain_nodes(finding_id);
```

### 2.10 attack_chain_edges — 攻击链边表

```sql
CREATE TABLE attack_chain_edges (
    id              VARCHAR(40)   PRIMARY KEY,          -- edge_01
    chain_id        VARCHAR(40)   NOT NULL REFERENCES attack_chains(id) ON DELETE CASCADE,
    source_node     VARCHAR(40)   NOT NULL REFERENCES attack_chain_nodes(id) ON DELETE CASCADE,
    target_node     VARCHAR(40)   NOT NULL REFERENCES attack_chain_nodes(id) ON DELETE CASCADE,
    trigger_condition TEXT,                             -- 读取 users 表获取管理员 hash
    privilege_escalation VARCHAR(100),                  -- anonymous → authenticated
    step            INTEGER       NOT NULL,             -- 1, 2, 3...

    CONSTRAINT chk_no_self_edge CHECK (source_node != target_node)
);

CREATE INDEX idx_chain_edges_chain ON attack_chain_edges(chain_id);
CREATE INDEX idx_chain_edges_source ON attack_chain_edges(source_node);
CREATE INDEX idx_chain_edges_target ON attack_chain_edges(target_node);
```

## 3. SQLAlchemy ORM 模型定义（Python 代码）

> 以下为后端 `backend/app/models/` 下的 ORM 模型定义，可直接用于建表。

```python
# backend/app/models/__init__.py
from datetime import datetime
from decimal import Decimal
from sqlalchemy import (
    String, Integer, BigInteger, Text, Boolean, Decimal as SQLDecimal,
    JSON, DateTime, ForeignKey, Index, CheckConstraint
)
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column, relationship
from sqlalchemy.dialects.postgresql import JSONB
from sqlalchemy import func


class Base(DeclarativeBase):
    pass


class Project(Base):
    __tablename__ = "projects"

    id: Mapped[str] = mapped_column(String(40), primary_key=True)
    project_name: Mapped[str] = mapped_column(String(200), nullable=False)
    source_type: Mapped[str] = mapped_column(String(20), nullable=False)
    source_input: Mapped[str] = mapped_column(Text, nullable=False)
    source_ref: Mapped[str | None] = mapped_column(String(100))
    commit_id: Mapped[str | None] = mapped_column(String(64))
    tech_stack: Mapped[list] = mapped_column(JSONB, default=list)
    status: Mapped[str] = mapped_column(String(20), default="active")
    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), server_default=func.now())
    updated_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), server_default=func.now(), onupdate=func.now())

    tasks: Mapped[list["Task"]] = relationship(back_populates="project", cascade="all, delete-orphan")
    snapshots: Mapped[list["SourceSnapshot"]] = relationship(back_populates="project", cascade="all, delete-orphan")

    __table_args__ = (
        Index("idx_projects_status", "status"),
        Index("idx_projects_created", "created_at"),
    )


class SourceSnapshot(Base):
    __tablename__ = "source_snapshots"

    id: Mapped[str] = mapped_column(String(40), primary_key=True)
    project_id: Mapped[str] = mapped_column(ForeignKey("projects.id", ondelete="CASCADE"))
    snapshot_path: Mapped[str] = mapped_column(Text, nullable=False)
    commit_id: Mapped[str | None] = mapped_column(String(64))
    file_count: Mapped[int | None] = mapped_column(Integer)
    total_size_kb: Mapped[int | None] = mapped_column(BigInteger)
    checksum: Mapped[str | None] = mapped_column(String(64))
    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), server_default=func.now())

    project: Mapped["Project"] = relationship(back_populates="snapshots")

    __table_args__ = (Index("idx_snapshots_project", "project_id"),)


class Task(Base):
    __tablename__ = "tasks"

    id: Mapped[str] = mapped_column(String(40), primary_key=True)
    project_id: Mapped[str] = mapped_column(ForeignKey("projects.id", ondelete="CASCADE"))
    sandbox_id: Mapped[str | None] = mapped_column(String(40))
    status: Mapped[str] = mapped_column(String(20), default="created")
    current_phase: Mapped[str | None] = mapped_column(String(30))
    phase_status: Mapped[dict] = mapped_column(JSONB, default=lambda: {
        "recon": "pending", "code_audit": "pending",
        "poc_verify": "pending", "exploit_chain": "pending", "report_gen": "pending"
    })
    sandbox_image: Mapped[str] = mapped_column(String(200), default="python:3.12-slim")
    network_mode: Mapped[str] = mapped_column(String(20), default="restricted")
    timeout_secs: Mapped[int] = mapped_column(Integer, default=1800)
    llm_mode: Mapped[str] = mapped_column(String(20), default="demo")
    max_concurrent: Mapped[int] = mapped_column(Integer, default=4)
    error_message: Mapped[str | None] = mapped_column(Text)
    resource_usage: Mapped[dict] = mapped_column(JSONB, default=lambda: {
        "cpuPercent": 0, "memoryMB": 0, "diskMB": 0, "elapsedSecs": 0
    })
    started_at: Mapped[datetime | None] = mapped_column(DateTime(timezone=True))
    ended_at: Mapped[datetime | None] = mapped_column(DateTime(timezone=True))
    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), server_default=func.now())
    updated_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), server_default=func.now(), onupdate=func.now())

    project: Mapped["Project"] = relationship(back_populates="tasks")
    findings: Mapped[list["Finding"]] = relationship(back_populates="task", cascade="all, delete-orphan")
    logs: Mapped[list["TaskLog"]] = relationship(back_populates="task", cascade="all, delete-orphan")
    report: Mapped["Report | None"] = relationship(back_populates="task", cascade="all, delete-orphan")
    runtime_profile: Mapped["RuntimeProfile | None"] = relationship(back_populates="task", cascade="all, delete-orphan")
    attack_chains: Mapped[list["AttackChain"]] = relationship(back_populates="task", cascade="all, delete-orphan")

    __table_args__ = (
        Index("idx_tasks_project", "project_id"),
        Index("idx_tasks_status", "status"),
        Index("idx_tasks_current_phase", "current_phase"),
    )


class RuntimeProfile(Base):
    __tablename__ = "runtime_profiles"

    id: Mapped[str] = mapped_column(String(40), primary_key=True)
    task_id: Mapped[str] = mapped_column(ForeignKey("tasks.id", ondelete="CASCADE"))
    language: Mapped[str | None] = mapped_column(String(50))
    framework: Mapped[str | None] = mapped_column(String(100))
    dependencies: Mapped[list] = mapped_column(JSONB, default=list)
    run_command: Mapped[str | None] = mapped_column(Text)
    service_ports: Mapped[list] = mapped_column(JSONB, default=list)
    entry_points: Mapped[list] = mapped_column(JSONB, default=list)
    db_type: Mapped[str | None] = mapped_column(String(50))
    raw_result: Mapped[dict | None] = mapped_column(JSONB)
    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), server_default=func.now())

    task: Mapped["Task"] = relationship(back_populates="runtime_profile")

    __table_args__ = (Index("idx_runtime_profiles_task", "task_id"),)


class Finding(Base):
    __tablename__ = "findings"

    id: Mapped[str] = mapped_column(String(40), primary_key=True)
    task_id: Mapped[str] = mapped_column(ForeignKey("tasks.id", ondelete="CASCADE"))
    vuln_type: Mapped[str] = mapped_column(String(100), nullable=False)
    cwe_id: Mapped[str | None] = mapped_column(String(20))
    status: Mapped[str] = mapped_column(String(20), default="unverified")
    severity: Mapped[str] = mapped_column(String(20), nullable=False)
    cvss_score: Mapped[Decimal | None] = mapped_column(SQLDecimal(3, 1))
    cvss_vector: Mapped[str | None] = mapped_column(String(200))
    source_file: Mapped[str | None] = mapped_column(Text)
    source_line: Mapped[int | None] = mapped_column(Integer)
    source_code: Mapped[str | None] = mapped_column(Text)
    sink_file: Mapped[str | None] = mapped_column(Text)
    sink_line: Mapped[int | None] = mapped_column(Integer)
    sink_code: Mapped[str | None] = mapped_column(Text)
    taint_path: Mapped[list | None] = mapped_column(JSONB)
    code_context: Mapped[str | None] = mapped_column(Text)
    detected_by: Mapped[str | None] = mapped_column(String(50))
    confidence: Mapped[Decimal | None] = mapped_column(SQLDecimal(3, 2))
    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), server_default=func.now())
    updated_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), server_default=func.now(), onupdate=func.now())

    task: Mapped["Task"] = relationship(back_populates="findings")
    evidences: Mapped[list["PocEvidence"]] = relationship(back_populates="finding", cascade="all, delete-orphan")
    patches: Mapped[list["FixPatch"]] = relationship(back_populates="finding", cascade="all, delete-orphan")

    __table_args__ = (
        Index("idx_findings_task", "task_id"),
        Index("idx_findings_status", "status"),
        Index("idx_findings_severity", "severity"),
        Index("idx_findings_cwe", "cwe_id"),
        Index("idx_findings_task_status_severity", "task_id", "status", "severity"),
    )


class PocEvidence(Base):
    __tablename__ = "poc_evidence"

    id: Mapped[str] = mapped_column(String(40), primary_key=True)
```

## 4. 索引策略说明

| 查询场景 | 对应索引 | 说明 |
|----------|----------|------|
| 项目列表分页 | `idx_projects_created` | 按创建时间倒序 |
| 任务列表按项目筛选 | `idx_tasks_project` | 项目下查任务 |
| 运行中任务检索 | `idx_tasks_status` | 仪表盘实时状态 |
| 漏洞按任务+状态+严重等级筛选 | `idx_findings_task_status_severity` | 最常见的前端列表查询 |
| 日志按任务+阶段过滤 | `idx_logs_task_phase` | 工作台日志按阶段切换 |
| 攻击链节点按链查询 | `idx_chain_nodes_chain` | 渲染攻击链拓扑图 |
| 审计日志按时间倒序 | `idx_audit_timestamp` | 配置页审计日志浏览 |

## 5. 数据保留与清理策略

| 数据 | 保留策略 | 说明 |
|------|----------|------|
| projects / tasks | 不自动清理 | 用户手动删除 |
| task_logs | 保留 30 天 | 超期自动清理（定时任务） |
| source_snapshots | 任务完成后保留 7 天 | 超期清理文件，DB 记录保留 |
| poc_evidence 响应报文 | 永久保留 | 作为验证证据 |
| reports 导出文件 | 永久保留 | 交付物 |
| audit_logs | 保留 90 天 | 合规要求 |

> 清理任务建议用 APScheduler 每日凌晨 02:00 执行，不做硬性要求，M1 阶段可不实现。
